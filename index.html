Make your first change

Your first contribution doesn't have to be complicated.

1

Find your folder

Look for students/your-github-username/ in the repository. If it doesn't exist, create it.

2

Edit your profile

Open profile.json and change your name, bio, or favourite technology.

3

Add a photo optional

Add a photo.jpg in the same folder. Keep it small (under 500KB).

4

Commit & push

Save your changes, commit them, and push to your fork.

5

Open a Pull Request

Go to the original repository and click New Pull Request. Your teacher will merge it.

What your profile.json looks like

{
  "name": "Rahul Kumar",
  "github": "rahul_dev",
  "about": "Trying web development for the first time.",
  "favoriteTech": "JavaScript",
  "image": "./photo.jpg"
}

name — your full name github — your GitHub username about — a short bio (one sentence) favoriteTech — something you're learning image — path to your photo (optional)
